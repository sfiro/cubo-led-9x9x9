# Versión 5.3: la lista pública de productos

**Etiqueta:** `asistente-v5.3` · **Fecha:** 2026-11-16 · **Basada en:** [v5.2](v5.2.md)

La lista de productos de Cali Abstracto ahora **está en GitHub**, en
`asistente_voz/conocimiento/productos_publicos.csv`. La Pi la recibe con `git pull` y ya no
hace falta copiarle el Excel a mano.

## Qué tiene la lista

Es la base de productos con solo lo que el cubo puede decir:

| Columna | Contenido |
|---|---|
| `Producto` | La categoría, tal como está en la base ("Iman", "Llaveros", "Libreta AA"…) |
| `Diseño` | El diseño ("Ermita", "gato tejada", "Chocolate 70% con piña"…) |
| `Material` | El material de la base ("Triplex", "PLA"…). `nombres_productos.md` dice cómo se pronuncia |
| `Ciudad` | Solo si es una ciudad de origen (Salento, Filandia…). **El proveedor se borra** |
| `Precio` | El precio de venta al público |
| `Activo` | Siempre 1: solo se publican los productos activos |

**No están:** el costo, el precio al por mayor, el proveedor, el código del producto, el QR, la
imagen, el usuario ni los productos inactivos. Tiene 1335 productos, los mismos que la v5.1
importaba del Excel.

## Cómo se actualiza (cuando cambian productos o precios)
1. Exportar la base desde el sistema de la tienda.
2. En el Mac, generar la lista pública:
   ```bash
   cd asistente_voz/raspberry && python3 productos.py --publico ~/Downloads/Users.xlsx
   ```
3. Subirla a GitHub (commit y push).
4. En la Pi: `git pull` y reiniciar el asistente. Al arrancar, importa la lista nueva.

Si en la Pi también hay un `productos.xlsx`, el asistente usa **el archivo más reciente** de los
dos. Después de un `git pull`, ese suele ser la lista pública.

## Cambios en el código
- `raspberry/productos.py`:
  - `exportar_publico()` y la opción `--publico`;
  - `productos_publicos.csv` entra en las bases que se importan;
  - `preparar()` usa la base más reciente.
- `.gitignore`: una excepción para `productos_publicos.csv`. Los demás `.csv`, el Excel,
  `productos.json` y `catalogo.md` siguen fuera del repo.
- `raspberry/asistente.py`: `VERSION = "5.3"`.

## Cómo se probó
En la Mac:
- **Generación desde la base real:** 1335 productos.
  - La columna `Ciudad` quedó vacía en todos, porque los productos de ciudades de origen están
    inactivos, así que no se publicó ningún proveedor.
  - Algunos nombres de proveedor aparecen dentro de **diseños**, porque son parte del nombre del
    producto en la base: "cali la sucursal del cielo", "Impresion 3D", "maxticafe 160g".
- **Importación desde la lista pública**, sin el Excel: los mismos 1335 productos y las mismas
  respuestas que en la v5.1:
  - el imán de la Ermita, a 7000 y 10 000 pesos;
  - los llaveros del gato de Tejada, a 12 000;
  - las tazas, como resumen;
  - los chocolates;
  - las camisetas, nada.
- `git status` confirma que solo se sube `productos_publicos.csv`, y no `productos.json` ni
  `catalogo.md`.

## Ojo
**El repositorio es público:** cualquiera puede ver la lista de productos y sus precios de
venta. Son los mismos precios que ve un cliente en la tienda, pero si algún día no quieres
publicarlos, hay que quitar el archivo del repo y volver a copiar el Excel a mano (v5.1).
