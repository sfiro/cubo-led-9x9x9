# Versión 5.2: la base de conocimiento de Cali Abstracto

**Etiqueta:** `asistente-v5.2` · **Fecha:** 2026-11-16 · **Basada en:** [v5.1](v5.1.md)

La base de conocimiento de la tienda ahora **está en GitHub**, en `asistente_voz/conocimiento/`.
La Pi la recibe con `git pull`, sin copiar archivos a mano. Está armada con la información
pública de la tienda:
[cali.ingenioabstracto.co](https://cali.ingenioabstracto.co/), la ficha de Google Maps "Cali
Abstracto artesanias" e [ingenioabstracto.co](https://ingenioabstracto.co/).

| Archivo | Contenido |
|---|---|
| `negocio.md` | Quiénes somos, Ingenio Abstracto, dirección y cómo llegar, horarios, cómo hacemos los productos, la colección de Cali (íconos, dichos caleños, La Sucursal del Cielo, sabor del Valle), tipos de productos, otros artesanos, personalizados, al por mayor, contacto y redes, opiniones de los clientes |
| `preguntas_frecuentes.md` | 11 respuestas exactas: quién eres, qué es Cali Abstracto, horario, dirección, material, qué recuerdo llevar, personalizados, al por mayor, WhatsApp, redes, otras sedes |
| `personalidad.md` | Cubo de Cali Abstracto, con un toque caleño |
| `cali.md` | La guía de Cali, con la sección "Artesanías en Cali" |
| `nombres_productos.md` | Nombres de las categorías de la base: "Libreta AA" se dice "libreta doble A", "Porta candela" se dice "portacandela" |

Faltan los **medios de pago** y los **envíos** (`[COMPLETAR]`). Mientras tanto, el cubo dice
que no tiene esos datos y que pregunten en caja.

## Qué se sube y qué no

| Se sube (repo público) | No se sube (`.gitignore`) |
|---|---|
| Los `.md` de `conocimiento/` | `productos.xlsx`, `.xls` y `.csv`: la base de productos, con costos internos |
| | `productos.json` y `catalogo.md`: se generan en la Pi desde la base |
| | `raspberry/.cache_conocimiento.json` |

Todo lo que está en los `.md` ya era público en la web y en Google Maps de la tienda. **El
repositorio es público**: no hay que poner en `conocimiento/` nada que no se quiera mostrar.

## Cómo se edita desde ahora
1. Se edita en el Mac, en `asistente_voz/conocimiento/`.
2. Se sube a GitHub (commit y push).
3. En la Pi: `git pull` y reiniciar el asistente.

Si se edita algo directamente en la Pi, `git pull` puede fallar por conflicto. Mejor editar
siempre en el Mac.

## Actualizar desde la v5.1 (una sola vez)
La Pi ya tiene una carpeta `conocimiento/` creada por `instalar.sh`, con las plantillas y
`productos.xlsx`. Como esos archivos no estaban en el repo, `git pull` se negaría a
reemplazarlos. Por eso hay que apartarlos primero y luego devolver solo la base de productos:
```bash
cd ~/cubo-led-9x9x9/asistente_voz
```
```bash
mv conocimiento conocimiento_anterior
```
```bash
cd .. && git pull
```
```bash
cp asistente_voz/conocimiento_anterior/productos.xlsx asistente_voz/conocimiento/
```
La carpeta `conocimiento_anterior` queda como respaldo y se puede borrar después de probar.

## Cambio en el código
- `raspberry/conocimiento.py`: la búsqueda por palabras (la que se usa si no está `bge-m3`)
  entiende plurales. "¿De qué material son?" ahora encuentra la sección que habla de
  "materiales".
- `raspberry/asistente.py`: `VERSION = "5.2"`.

## Cómo se probó
En la Mac, con la búsqueda por palabras (sin Ollama):
- Se cargan 27 secciones y 11 preguntas frecuentes, con 2 párrafos sin completar.
- Responden como pregunta frecuente: "¿A qué hora cierran hoy?", "¿Cómo llego a la tienda?",
  "¿Qué me recomiendas de recuerdo?" y "¿Tienen TikTok?".
- "¿Qué es el Jeep Willys?" encuentra "La colección de Cali".
- Antes de subir, se revisó que `productos.xlsx`, `productos.json` y `catalogo.md` quedan
  fuera del repo.
